# Mentiohunt — Pricing Direction

Market price anchors: roughly **$160–$500 per link** in productized offers, with agencies often higher.

## Best pricing shapes

### Option A: Per-placement pricing

- Clear and easy to understand
- Best for founder-led SaaS
- Can tier by quality/relevance class

### Option B: Monthly managed credits / placement budget

- Better for predictable throughput
- Easier for agencies and repeat buyers
- Keeps "autopilot" feeling stronger

### Option C: Hybrid

- Base monthly platform/service fee
- Plus per confirmed placement

## Pricing principle

Charge for:
- quality tier
- relevance tier
- content type / placement type
- optional manual review / higher control tiers

Do **not** compete on cheapest-links positioning.
