## Why a live check beats a stale snapshot

Most "backlink checker" tools show you data from whenever their index last crawled a page — that can be weeks or months old. If a site quietly removed your link last month, a stale index still shows it as live. This tool skips the index and fetches the actual page right now, so the status you see is the status today.

## What it checks per link

For each page URL you paste, it looks for a link pointing at your domain and reports one of:

- **Live · dofollow** — the link is there, no nofollow-family `rel` attribute, still passing ranking signal.
- **Live · nofollow** — the link is there but marked `nofollow`, `ugc`, or `sponsored`.
- **Link removed** — the page loads fine, but your link is no longer on it.
- **Page down** — the source page itself returns an error or won't load.
- **Couldn't check** — a transient fetch issue (rare); rerun the check if you see this.

## How to use it after a placement lands

Whenever an outreach effort lands a new link — a guest post goes live, a resource page adds you, a journalist links your product — save the page URL. Come back and paste your list here every so often to confirm nothing quietly broke. It's the same idea as checking [dofollow vs nofollow](/free-tools/dofollow-link-checker) on a single page, just applied across every placement you've earned at once.
