## Why the dofollow / nofollow distinction matters

Not every backlink is worth the same. A dofollow link is a normal editorial link — no `rel` attribute telling search engines to disregard it — and it's the kind of link that actually contributes ranking signal. A nofollow, ugc, or sponsored link still sends traffic and can still matter for visibility, but it doesn't pass the same weight.

When you're evaluating a placement — whether it's one you just landed or one a competitor has — knowing which type it is changes how much it's actually worth to your link building effort.

## What the checker looks at

Paste any page URL above and it scans the live HTML for every `<a>` tag, resolves relative links to full URLs, and classifies each one:

- **Dofollow** — no nofollow-family `rel` value, passes ranking signal.
- **Nofollow** — explicitly marked to not pass signal.
- **Ugc** — nofollow variant for user-generated content like comments.
- **Sponsored** — nofollow variant for paid or affiliate links.

It also splits every link into **internal** (same domain) and **external** (off the site), since the dofollow/nofollow question usually only matters for external links — internal link structure is a separate concern.

## How to use it when checking your own backlinks

If a site agreed to link to you, don't just confirm the link exists — check whether it's dofollow. Paste the page URL where your link lives, filter to external links, and find your domain in the list. If it came back nofollow and you expected dofollow, that's worth a follow-up email before you count the placement as done.
